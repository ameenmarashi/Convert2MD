    Why Markdown, in a nutshell

    Markdown is plain text with a handful of marks for structure — # for a heading, - for a list item. That is the whole format.

    It outlives the software that wrote it, and keeps structure without dragging fonts and page margins along. One small file, no container, no hidden revision history.

    It is also the format AI tools already speak: models write their answers in Markdown and read it back with the structure intact, so a converted document arrives as headings and tables rather than one flat run of words — and you can see everything you are about to paste.

      Privacy — your files are never collected ▾

      Nothing you open here is uploaded, stored, logged or shared. Not with a server, not with an AI company, not with the developer.

      • Your documents are never uploaded. They are read by this tab, converted by code running on your own device, and gone the moment you close it. There is no server to send them to.
      • They are never used to train or prompt any AI. No model sees them. Nothing is sent to OpenAI, Anthropic, Google or anyone else. The conversion is ordinary parsing code, not a language model.
      • The developer cannot see what you convert. Not by policy — by construction. There is no account, no database and no log, so there is nothing to look at even in principle.
      • No analytics, no cookies, no tracking. The app loads no third-party scripts and makes no network requests of its own. The typeface is bundled with it rather than fetched from a font service.
      • Only your settings are stored. Your conversion preferences, theme and reading size are kept in this browser’s local storage. Document content never is.

      The one exception, stated plainly: if a document you convert links to an image hosted on the web, the preview will load that image from wherever it lives, exactly as any viewer would. Set Images to “Leave out entirely” in Conversion settings if you would rather it never did.

      You can check all of this: turn off the network — after installing the app — and convert a file. It still works, because there was never anything on the other end.

      Why Markdown, and why AI tools speak it ▾

      Markdown is plain text with a handful of marks for structure — # for a heading, - for a list item, | for a table. That is the whole format, and it is why it lasts.

      1. It outlives the software that wrote it

        A .docx needs Word. A .md file opens in any text editor, on any device, in twenty years.

      2. Structure survives; styling gets out of the way

        Headings, lists, tables and links are kept as meaning. Fonts, margins and page breaks — which only ever served the printed page — are dropped.

      3. It is searchable, diffable, versionable

        Plain text means grep finds it and Git tracks every change line by line — so you can see exactly what moved between two drafts.

      4. It is one small file

        No zip container, no embedded metadata, no tracked changes or comment threads travelling silently with the document.

      Markdown and AI

      Markdown has quietly become the language models and people share. It is worth knowing why.

      1. It is what the models already write

        Ask ChatGPT, Claude or Gemini for anything structured and the answer comes back as Markdown — headings, bullets, tables, fenced code. Saving that reply as a .md file keeps it exactly as written, which is why so many people end up with a folder of them.

      2. It is what they read best

        A model sees your document as text. Hand it a PDF and the headings, columns and tables usually arrive as one flat run of words. Convert first and the structure arrives intact, so the model can tell a heading from a sentence and a table row from a paragraph.

      3. It spends your context window on content

        Word and HTML carry far more markup than text — tags, styles and identifiers the model must read and pay for. Markdown adds a handful of characters per heading. More of the window goes to what the document actually says.

      4. It chunks along meaning

        Retrieval pipelines split documents before searching them. With Markdown headings the splits fall at section boundaries instead of arbitrary page breaks, so a retrieved passage is a whole idea rather than half of two.

      5. You can see everything you are about to send

        An office file carries things you cannot see: tracked changes, resolved comments, author names, revision history, hidden sheets. Paste one into a chat and all of it goes along. A Markdown file is exactly what is on the screen — which matters most when the document was confidential to begin with.

      Converting to Markdown keeps the content and drops everything that was only there to serve the page — or that you never meant to send.

      New to Markdown? The whole thing in nine lines ▾

      You never have to type these — the buttons above do it. But this is all there is.

      You typeYou get
      # TitleA big heading
      ## SectionA smaller heading
      **bold**bold
      *italic*italic
      - itemA bulleted list
      1. itemA numbered list
      - [ ] taskA checklist you can tick
      [text](address)A link
      > wordsA quote, set apart

      You are editing the document, not the marks. What you see is what the file looks like, and the buttons above format it the way a word processor would. Press ⌨ Markdown if you would rather see the marks — the file is the same either way.

      Photos go inside the document itself, so there is only ever one file to keep. They are shrunk to a sensible size first, and like everything else here they never leave this device.

      Two things the Markdown view does for you: press Enter in a list and the next item appears by itself — press it again on an empty item to end the list. Press Tab on a list item to nest it underneath the one above.

      A blank line separates paragraphs. That is genuinely the whole format.
