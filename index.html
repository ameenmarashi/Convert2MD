    Why Markdown, in a nutshell

    Markdown is plain text with a handful of marks for structure — # for a heading, - for a list item, | for a table. That is the whole format, and it is why it lasts.

    1. It outlives the software that wrote it

      A .docx needs Word. A .md file opens in any text editor, on any device, in twenty years.

    2. Structure survives; styling gets out of the way

      Headings, lists, tables and links are kept as meaning. Fonts, margins and page breaks — which only ever served the printed page — are dropped.

    3. It is what AI tools read best

      Language models, retrieval pipelines, static site generators and note apps take Markdown directly, with no conversion layer in between.

    4. It is searchable, diffable, versionable

      Plain text means grep finds it and Git tracks every change line by line — so you can see exactly what moved between two drafts.

    5. It is one small file

      No zip container, no embedded metadata, no tracked changes or comment threads travelling silently with the document.

    Converting to Markdown keeps the content and drops everything that was only there to serve the page.

    What this app does

    Drop a document in; get a Markdown file out. Every conversion runs on this device — there is no server, nothing is uploaded, and no account is needed.

    1. 1

      Reads the real file

      It opens the actual container — the OOXML parts inside a .docx, the object graph inside a PDF — rather than scraping visible text.

    2. 2

      Recovers the structure

      Headings, ordered and bulleted lists, tables, links, footnotes, speaker notes and images are identified. In PDFs, which carry no structure at all, headings and paragraphs are inferred from font size and layout, and repeating headers and footers are dropped.

    3. 3

      Writes clean Markdown

      Preview it, copy it, download it, or export everything at once as a .zip. Optional YAML front matter records the title, author and source file.

    Nothing leaves the device

    There is no server and no upload. Files are read in this tab, converted here, and forgotten when you close it — which is what makes it safe for patient records, contracts and anything else confidential.

    Installed means offline

    Add it to your Home Screen or Dock and the whole app — including the PDF and Word engines — is stored on the device. It keeps working on a plane, in a basement, with the network off.

    Built to read documents properly

    Every parser is written into the app itself: no libraries fetched at runtime, nothing to load before it can work. That is what lets it run with no connection at all.
